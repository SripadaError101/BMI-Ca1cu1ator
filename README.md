BMI Calculator

A simple web page that calculates your BMI from height and weight, shows your category (Underweight, Normal, Overweight or Obese), and gives the healthy weight range for your height. Built with plain HTML, CSS and JavaScript.

How to run

Open index.html in any browser. No installation needed.

How to use
Enter your height in cm
Enter your weight in kg
Click Calculate BMI
Note

BMI is a general screening measure and doesn't account for muscle, age or body type. Talk to a doctor for personal advice.
